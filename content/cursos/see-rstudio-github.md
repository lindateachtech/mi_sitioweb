¿Cuántas veces has guardado un archivo como `analisis_final_v3_DEFINITIVO.R`? En este taller aprenderás a dejar eso atrás y a trabajar con control de versiones usando GitHub directamente desde RStudio, para que tus proyectos tengan historial, estén respaldados y puedas compartirlos con quien quieras.

## ¿Para quién es?

El taller está pensado para personas que ya trabajan con R y RStudio. No vamos a aprender a usar RStudio, sino a versionar y compartir proyectos, así que lo aprovecharás mucho más si ya escribes tus propios scripts o informes.

## ¿Qué aprenderás?

- Qué son Git y GitHub y cómo es el flujo de trabajo con control de versiones.
- Cómo conectar RStudio con Git y GitHub de forma segura.
- Cómo crear un proyecto nuevo versionado y cómo versionar uno que ya tienes.
- Cómo hacer commits, subir cambios y revisar el historial de tu proyecto.
- Cómo compartir tu proyecto con un buen README y sin subir lo que no debes.

Empezaremos con una breve presentación de [rOpenSci](https://ropensci.org/), la comunidad que impulsa software científico abierto y reproducible en R. Este taller forma parte de mi participación en su programa Champions 2026.

## Antes del taller

Para seguir el taller necesitas:

- Git instalado, 
- Una cuenta de GitHub
- Los paquetes `usethis` y `gitcreds` instalados en R.

Toda la configuración la haremos juntos durante el taller.

En el repositorio encontrarás la guía de instalación paso a paso.
