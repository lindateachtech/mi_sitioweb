¿Cuántas veces has guardado un archivo como `informe_final_v3_DEFINITIVO.pbix`? En este taller aprenderás a dejar eso atrás y a trabajar con control de versiones en tus proyectos de Power BI usando Git y GitHub, directamente en formato `.pbip`, para que tus informes tengan historial, estén respaldados y puedas compartirlos con quien quieras.

## ¿Para quién es?

El taller está pensado para personas que ya trabajan con Power BI. No vamos a aprender a usar Power BI, sino a versionar y compartir informes, así que lo aprovecharás mucho más si ya construyes tus propios reportes.

## ¿Qué aprenderás?

- Qué son Git y GitHub y cómo es el flujo de trabajo con control de versiones aplicado a un informe `.pbip`.
- Cómo conectar tus proyectos de Power BI a Git y GitHub desde VS Code.
- Dos caminos para empezar: partir de un informe que ya tienes en tu computadora y subirlo a GitHub (local primero), o crear primero el repositorio en GitHub y traerlo a tu computadora (GitHub primero).
- Cómo hacer commits, subir cambios y revisar el historial de tu informe.
- Cómo usar un asistente de IA como apoyo durante el flujo de Git, de forma opcional.

El taller es gratuito y abierto, y la SEE lo transmite en abierto en su cuenta de Facebook y en YouTube.

## Antes del taller

Para seguir el taller necesitas:

- Power BI Desktop y Visual Studio Code instalados.
- Git instalado.
- Una cuenta de GitHub.

Si quieres usar un asistente de IA durante la parte de Git, puedes traer tu propia cuenta.

Toda la configuración la haremos juntos durante el taller.
